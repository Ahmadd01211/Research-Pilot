# Cited Research Chat preview

The browser sends a question and up to ten selected document IDs to `POST /api/v1/projects/{project_id}/evidence/answer`. The server first runs the existing owner-scoped, current-index vector search. It sends at most eight bounded retrieved excerpts, not entire PDFs, to the independently configured answer model. The answer response is structured as statements with source IDs; the server rejects invented or duplicate IDs and exposes the linked source excerpt and original-PDF location for every statement. If the retrieved material cannot answer the question, it returns an explicit insufficient-evidence state. The model can still misread a real passage, so a citation is a verification path rather than a correctness guarantee.

The feature is off by default. On the server, set `RP_EMBEDDING_ENABLED=true`, `RP_ANSWER_ENABLED=true`, and `RP_GOOGLE_API_KEY` in the untracked `.env`, then restart the stack. `RP_ANSWER_MODEL` defaults to `gemini-3.8-flash` and can be changed independently of the embedding model without re-indexing. Check actual model access, data-use terms, quota, and pricing for the Google account first. A Pro preview model may require billing. The key never goes to the browser. Each account is limited to ten answer attempts per 15 minutes; this is a basic safeguard, not production billing or a full cost budget.

This first interaction is single-turn: each question searches the selected papers afresh. No conversation history is stored or sent to the model, and the page labels that limitation. This avoids letting an earlier, uncited answer contaminate a later one, but follow-up questions must include their full context. We will add persisted conversation threads only with per-turn evidence and provenance.

The current claim validator verifies source ID membership, not semantic entailment. The source excerpts and PDF links make human checking possible. Next, run a real-provider retrieval and answer evaluation on reviewed papers; test unsupported questions, conflicting papers, table values, cited figures, latency, and cost. Add usage accounting and a stronger budget policy before public release.
