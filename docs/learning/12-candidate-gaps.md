# Candidate research gaps

The gap workspace stores researcher-authored hypotheses, not AI-discovered facts. A candidate has a title, rationale, and up to twelve matrix fields marked as supporting or challenging evidence. At least one supporting field is required. The backend confirms every linked field belongs to an active matrix row in the same project and cites the current version of its paper. Gap links point through the matrix cell to the immutable evidence chunk and original PDF page.

The uncertainty label is a simple explanation of the reviewed evidence, not a probability of truth. One supporting paper yields **Limited coverage**. More than one supporting paper without linked challenges yields **Cross-paper candidate**. Linked challenges yield **Mixed evidence**. If a matrix row was removed or its reader version changed, **Source needs review** takes precedence. These labels do not establish that a topic is absent from the broader literature; researchers must expand and verify the search.

Candidates use revision checks for edits, soft removal, and a 100-active-candidate project limit. On an edit conflict, the editor loads the latest candidate and matrix, compares it with the unsaved title, rationale, and evidence selections, then lets the researcher keep the draft for a separate save or explicitly load the latest candidate. Evidence links that no longer exist in the latest matrix are excluded when resolving the conflict and must be selected again if still relevant. A retry remains available when the latest version cannot be fetched. Archived projects remain readable. The screen shows supporting and challenging notes side by side, plus PDF links for each. Matrix edits preserve earlier cells as superseded records; a candidate citing one shows **Source needs review**, and its editor asks the researcher to choose current supporting evidence. Later AI assistance may suggest candidate patterns, but it must cite eligible matrix cells, expose counterevidence, avoid claims based solely on missing fields, and mark suggestions as unreviewed until a researcher accepts them.
