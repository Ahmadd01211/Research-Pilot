# ADR 0006 — Original PDF, readable passages and measured anchors

19 October 2026. Implements the user's request for original-format reading alongside readable source text and passage highlighting.

PDF.js 6.4.299 is pinned and lazy-loaded. The reader fetches the authenticated original once, verifies SHA-256 against the owned evidence response, and passes only verified bytes to PDF.js. No iframe, object URL, external CDN, embedded-PDF scripting, interactive forms or annotation-action layer is used. XFA and WebAssembly are disabled. The explicit isEvalSupported:false compatibility option is retained; installed PDF.js 6 types no longer list it, so this option alone is not a security guarantee. Strict existing CSP excludes unsafe-eval; no security headers were relaxed. Local module-worker .mjs files have an explicit JavaScript MIME mapping with inherited security headers. Fonts/CMaps and only inert image decoder fallbacks/licenses are copied from the pinned package at build/dev startup; the optional QuickJS scripting evaluator is not served.

Canvas rendering is bounded to 12 million pixels and 8000 pixels on the longest side; image decode limits apply. The original still remains untrusted, dependencies require ongoing maintenance, and browser rendering is not a complete security sandbox. Unsupported/complex features may differ from a dedicated PDF reader; downloading the original remains available. The canvas has an accessible label and a selectable text alternative beside it. Users can choose both, PDF-only or text-only; narrow screens stack the panels. Zoom/page navigation have actual actions. Loading/errors are visible and stale canvas content is hidden.

The existing pypdf extraction remains the raw text representation, with only its existing null-character/edge-whitespace handling. A bounded pdfplumber/pdfminer pass measures word boxes in the rotated CropBox coordinate system. Boxes are normalized to top-left fractions of the displayed page. Parser wall/memory/CPU limits remain enforced. Reader output is additionally bounded to 12k words/page, 200k/document and 2000 characters/word. Parent validation checks box ranges and word-index references; the subprocess JSON cap grows to 64 MB to accommodate coordinates.

Readable passages preserve measured source words. Font-relative spacing (x_tolerance_ratio=0.15) avoids the fixed-gap merging observed in the supplied academic paper. Ligatures expand; soft hyphens/nulls are removed and nonbreaking spaces normalized in this derivative only. No spelling repair, speculative dehyphenation, number conversion or AI rewriting is applied. Text order follows PDF text flow and can still be imperfect for tables, columns, mathematics and unusual encodings.

Repeated top/bottom margin lines and narrow side-margin text are excluded only after recurring on at least three pages and 40% of the document. Digits/whitespace are normalized only for matching recurring margin signatures, never to change displayed source words. Excluded text and all measured words remain stored/inspectable; the raw transcript is retained. This heuristic can miss or misclassify marginal content, so it is not a lossless semantic parser.

Passages carry deterministic SHA-256 IDs derived from reader/parser identity, physical page number, text and word boxes. Their word indices select measured boxes for the canvas highlight. Deep links include page, passage ID, original checksum and reader version. Unknown anchors, source/version mismatches and invalid pages never silently select a different passage. These are evidence anchors, not proof a generated claim is supported. Future RAG citations must reference actual retrieved passages.

Migration 0005 adds nullable document_pages.layout JSONB. New successful jobs persist raw text and layout together. Existing extracted documents remain unchanged until an owned CSRF-protected prepare-reader request queues a bounded upgrade. Archived/removed/foreign projects are denied. Preparation is allowed only for an extracted document missing layouts, so it cannot reset retry budgets repeatedly. There are no generated chat citations yet; before general reprocessing/version history is added, cited derived versions must be preserved explicitly. Immutable original files/checksums are retained.

The user selected Google-hosted embeddings and an independently configurable stronger chat model. That next phase is separate: no embedding provider/key, vector index or chat generation is implemented/called by this reader. Readable passages provide measured source anchors for later chunking and embeddings.
